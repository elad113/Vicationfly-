# ASHES OF ELDORIA: THE FALLEN CROWN

A landscape, mobile-first fantasy action RPG prototype built with Three.js and Capacitor. Features a procedural 3D realm, touch movement, camera control, enemy pursuit and attacks, spellcasting, interactable characters, quests, pickups, and local save state.

## Android APK
The GitHub Actions workflow **Build Android APK** builds a debug APK and uploads it as the `ashes-of-eldoria-apk` artifact. Open the Actions tab, select the latest workflow run, and download the artifact after it succeeds.

## Run locally
- Node.js 20+
- `npm install`
- `npm run dev`

## Controls
Left virtual stick: move. Drag the right side of the screen: rotate camera. **STRIKE**: melee attack. **EMBER**: fire spell. **DODGE**: quick evade. **TALK**: interact with the keeper, shrine, or pickups. Quest progress is saved locally.

This is an original playable prototype, not a claim of a finished large commercial open-world RPG.
